# Design References

## Inspiration Sources

### WaniKani
**Key Design Elements:**
- Clean white background with card-based layout
- Playful illustrations (crabigator mascot)
- Clear section organization with distinct cards
- Progress indicators with numbers in colored circles
- Color-coded sections (pink for lessons, blue for reviews)
- Simple, readable typography
- Organized grid layout (2-3 columns)
- Clear call-to-action buttons with icons
- Progress bars and visual indicators
- Status tags (e.g., "In Progress", "Not Started")

**Layout Structure:**
- Header with logo and navigation
- Main content in card grid
- Each card has: icon/number, title, subtitle, illustration, action button
- Bottom sections for detailed progress tracking

### NativShark
**Key Design Elements:**
- Dark purple/blue theme (dark mode focused)
- Modern dashboard with clean sections
- Horizontal banner-style progress indicators
- Phase-based learning path visualization
- Activity tracking with stats
- Clean typography with good contrast
- Organized dropdown menus
- Progress bars with visual elements
- Status indicators and badges

**Layout Structure:**
- Top navigation bar
- Main dashboard with "Today's studies" section
- Activity tracking section
- Learning path visualization
- Extra credit/optional features section

## Design Principles for NihonAI Tutor

### Color Palette
- **Primary**: Black/White (clean, professional)
- **Accents**: Purple/Blue for highlights (inspired by NativShark)
- **Status Colors**: 
  - Green for success/completed
  - Blue for active/in-progress
  - Pink/Purple for highlights
  - Red for errors/warnings

### Layout Principles
1. **Card-based design**: Each feature in its own card
2. **Clear hierarchy**: Large numbers for key metrics
3. **Playful but organized**: Friendly illustrations, but structured layout
4. **Progress visualization**: Clear progress bars and indicators
5. **Action-oriented**: Prominent buttons for main actions
6. **Responsive grid**: 2-3 columns on desktop, 1 column on mobile

### Typography
- Clean, readable fonts
- Large numbers for metrics
- Clear headings and subtitles
- Good contrast for readability

### UI Components
- Cards with rounded corners and shadows
- Colored circles/badges for numbers
- Progress bars
- Status tags
- Action buttons with icons
- Clean input fields
- Organized sections with clear separation
