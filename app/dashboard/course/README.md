# Course Session Implementation Notes

## Hiragana/Katakana Learning Methodology

**Important**: The current "Hiragana Basics" session is a mock that only teaches vocabulary. 

For actual Hiragana/Katakana learning, a different approach is required:

1. **Mnemonics-based learning**: Use visual mnemonics to remember the shape of each character
2. **Character recognition drills**: Focus on recognizing and writing characters, not vocabulary translation
3. **Quiz format adjustments**: 
   - Show character → user types romaji
   - Show romaji → user selects/identifies character
   - Show character → user writes/draws it
   - Mix of recognition and production exercises
4. **Repetitive drilling**: Requires many practice sessions to build muscle memory

The kana system is relatively easy to learn but requires dedicated drilling sessions with character-focused exercises, not vocabulary translation quizzes.
